# Copilot Project

This project is a simple web app built with Python and HTML.

## Features
- Displays a basic web page
- Runs locally through a Python server

## Run locally
1. Open the project folder.
2. Start the app with:
   ```bash
   python promt.py
   ```
3. Open http://localhost:8000 in your browser.

## Files
- `index.html` - Main webpage
- `promt.py` - Python server entry point
